# Conquest

Inputs : 
Clique gauche pour sélectionner, déplacer et poser une carte (drag n drop)
Clique droit pour tourner une carte


Pour le multijoueur :
- lancer la build sur 2 pc sur le même réseau
- un joueur créer et host la game, l'autre rejoint


Quand une partie est finie, écran de victoire pendant 10 secondes puis retour au menu principal
